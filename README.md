# Losowanie trendów

Prosty projekt React oparty na Vite. Na tym etapie zawiera tylko stronę startową — funkcja losowania trendów nie została jeszcze dodana.

## Wymagania

- Node.js 20.19+ lub 22.12+
- npm

## Uruchomienie lokalne

```sh
npm install
npm run dev
```

Adres aplikacji wyświetli się w terminalu Vite. Budowanie wersji produkcyjnej: `npm run build`.
